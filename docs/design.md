# FunCalc 交互设计

## 定位

随时唤出的计算笔记本。核心路径是「输入 → 看公式 → 计算 → 留下记录 → 复用」，不是模拟实体计算器的数字键盘。

## 页面

- 顶栏：品牌、使用指南、系统/浅色/深色选择。
- 主区顶部：始终可编辑的表达式，计算按钮，LaTeX 预览。错误紧邻输入框，成功由底部状态栏提示。
- 主区下方：历史搜索和记录。每条包含原表达式、当时的结果、时间、复制结果、复制 LaTeX、删除。最近结果有轻微强调。
- 右栏：变量名、类型、排版后的值；点击名称插入当前位置；`ans` 标注为上次结果。
- 空状态：三个可操作示例，帮助用户从算术、变量和矩阵开始。
- 小于 640px 时变量区移到主区之后；长矩阵在自己的公式区域横向滚动，不撑开页面。

## 语义

计算结果和变量使用同一个事务持久化，失败不显示已保存。每次显式计算都新增记录，相同表达式不会被悄悄合并。历史是快照，变量改变不修改旧结果；重算使用当前变量。

单条删除可撤销，清空全部需确认并保留变量。删除变量只影响未来计算。当前草稿在退出到后台时保留，不自动执行从主搜索带入的文字。

## 视觉与操作

桌面工具采用简洁平面布局、系统字体、蓝色强调和单色数学排版。不加载远程字体或图标。以键盘输入为主，功能通过文字按钮呈现，无需猜图标。

Enter 计算；Shift+Enter 换行编辑同一个表达式；Ctrl/Cmd+K 查历史；空输入框上方向键取上一条。中文输入法确认候选时不提交。所有操作保留可见焦点，错误使用 alert，状态提示使用 status，公式提供文本标签和 MathML。

## 第一版之外

暂不引入绘图、符号求导、单位换算、复数、方程求解、云同步和协作。历史暂按单个笔记本存储，列表分批展示；需要跨设备或超大规模记录时再设计迁移、分页查询与多笔记本。
